# rosduino_gen

[English](README.md)

**C++-заголовки для скетча RosDuino из файлов ROS 2 `.msg` и `.srv`.** В [библиотеке Arduino](https://github.com/rosduino/rosduino_arduino) уже лежат распространённые типы. Этот пакет пишет заголовки для остальных и умеет заново собрать тот же комплект.

```bash
ros2 run rosduino_gen rosduino-gen --package my_robot_msgs --out "$HOME/Arduino/libraries/RosDuino/src"
```

Обзор репозитория — [../README_RU.md](../README_RU.md). С платой говорит [`rosduino_agent`](../rosduino_agent/README_RU.md).

| | |
|---|---|
| Сборка | `ament_python` |
| Исполняемый файл | `rosduino-gen` |
| Лицензия | Apache-2.0 |

## Сборка

Из корня репозитория, с подключённым ROS 2:

```bash
source /opt/ros/$ROS_DISTRO/setup.bash
colcon build --packages-select rosduino_gen
source install/setup.bash
```

Генератор рассчитан на ROS 2 **Lyrical**.

## Генерация

```bash
ros2 run rosduino_gen rosduino-gen --list
ros2 run rosduino_gen rosduino-gen --list --package std_msgs
ros2 run rosduino_gen rosduino-gen --package std_msgs
ros2 run rosduino_gen rosduino-gen --package std_msgs --package sensor_msgs
ros2 run rosduino_gen rosduino-gen --all
```

Без `--out` заголовки пишутся в `generated/` этого пакета.

| Флаг | Эффект |
|---|---|
| `--list` | Напечатать имена интерфейсов (`pkg/msg/Name`, `pkg/srv/Name`) и выйти. Без `--package` — все интерфейсы, которые знает ROS 2 |
| `--package PKG` | Сгенерировать один пакет. Флаг можно повторить |
| `--all` | Очистить каталог вывода и сгенерировать типы из [`arduino_types.txt`](arduino_types.txt). Вложенные типы добавляются сами |
| `--out DIR` | Каталог вывода. По умолчанию `generated/` в этом пакете |
| `--default-seq-cap N` | Ёмкость неограниченного массива `T[]` (по умолчанию 8) |
| `--parser auto\|simple\|rosidl` | Парсер. `auto` берёт парсер ROS 2, если он установлен |

`--all` вместе с `--package` — ошибка. Нужен один из флагов `--package`, `--all` или `--list`.

## Куда класть заголовки

Сгенерированный `.h` попадает на плату, когда лежит в библиотеке Arduino рядом с `rosduino/`, в раскладке `pkg/msg/Name.h` или `pkg/srv/Name.h`.

| ОС | Исходники библиотеки |
|---|---|
| Linux | `~/Arduino/libraries/RosDuino/src/` |
| macOS | `~/Documents/Arduino/libraries/RosDuino/src/` |
| Windows | `Documents\Arduino\libraries\RosDuino\src\` |

`--out` может указывать прямо на этот каталог `src/`. Скетч подключает тип так же, как в ROS 2. Короткое имя без `msg` и `srv`:

```cpp
#include <my_robot_msgs/msg/Status.h>

my_robot_msgs::Status status;   // или my_robot_msgs::msg::Status
```

## Штатный комплект

[`arduino_types.txt`](arduino_types.txt) — список, который пишет `--all`. Строка — это пакет целиком или один тип (`pkg/msg/Name`, `pkg/srv/Name`). Вложенные типы перечисленного типа пишутся тоже. `--all` сначала очищает каталог вывода, поэтому файла вне этого списка там не остаётся.

Чтобы добавить свои типы в комплект, допишите их в `arduino_types.txt` и снова запустите `--all`.

Библиотека Arduino поставляется с результатом этого списка: `builtin_interfaces`, `std_msgs`, `std_srvs`, `example_interfaces` и выбранные типы `geometry_msgs`, `sensor_msgs` и `nav_msgs`.

## Что внутри заголовка

Первые строки — `Generated by rosduino-gen. Do not edit.`, затем имя `pkg/msg/Name` или `pkg/srv/Name`, затем полный текст исходного `.msg` или `.srv` строками `//`: поля, константы, `#`-комментарии и `---` сервиса. Вложенные типы в этот комментарий не разворачиваются.

Хеш RIHS01 берётся из `share/<pkg>/msg/<Type>.json` или `share/<pkg>/srv/<Type>.json`. Если файла нет, в заголовок пишется `0`, а генератор печатает предупреждение в stderr.

Эти заголовки на C++11, без кучи и без STL, поэтому собираются на Nano, Uno, Micro, Mega и Due. Это другой файл, не `.hpp`, который `rosidl_generator_cpp` пишет для узла на Linux. Сравнение по полям: [doc/arduino_due.md](doc/arduino_due.md).

Сервис — одна структура с `request` и `response`:

```cpp
#include <std_srvs/srv/SetBool.h>

std_srvs::SetBool srv;
srv.request.data = true;
```
